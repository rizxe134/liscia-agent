## Liscia Agent 3.0.1

### Fixed
- **Bots now work the same from the Chrome side panel.** Messages sent from the panel use that bot's instructions, memory, app connections and MCP tools, just like in the app window. Any change still waits for your approval.

### Download
| File | For |
|---|---|
| `Liscia-Agent-3.0.1-macos-arm64.dmg` | macOS (Apple Silicon) |
| `Liscia-Agent-3.0.1-windows-x64.zip` | Windows |
| `liscia-agent-chrome-extension-3.0.1.zip` | Chrome extension |

### Install
- **Mac:** open the dmg and drag Liscia Agent into Applications, replacing the old one.
- **Windows:** unzip and replace the old folder.
- **Extension:** the app reloads it automatically.
