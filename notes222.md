## Liscia Agent 2.2.2

- **Misspelled site names now work in multi-site requests.** In 2.2.1, "open up linkden then open up instagram on another tab" still fell through to the step-by-step browser loop. Now LinkedIn and Instagram both open directly, with Instagram in a new tab.

### Download
| Platform | File |
|---|---|
| macOS (Apple Silicon) | `Liscia-Agent-2.2.2-macos-arm64.dmg` |
| Windows (x64) | `Liscia-Agent-2.2.2-windows-x64.zip` |
| Chrome extension | `liscia-agent-chrome-extension-2.2.2.zip` (required for the cursor and banner) |

### Install
- **macOS:** open the dmg and drag **Liscia Agent** to Applications, replacing the old one.
- **Windows:** quit Liscia Agent, unzip, and replace the contents of `%LOCALAPPDATA%\Programs\Liscia Agent`.
- **Extension:** unzip it (or update your unpacked folder), open `chrome://extensions`, then click **Reload** on Liscia Agent. (From 2.2.0 on, Liscia Agent can reload the extension itself.)
